# 학생 기초조사 템플릿 시트 만들기 (제작팀용)

선생님이 **[템플릿 사본 만들기]** 한 번으로 Apps Script 코드가 들어 있는 시트를 받게 하려면, 제작팀이 템플릿 시트를 한 번 만들어 공개해 두어야 합니다.
템플릿이 없으면(`src/config.js`의 `SURVEY_TEMPLATE_COPY_URL`이 비어 있으면) 프로그램은 ‘새 시트에 코드 붙여넣기’ 방법만 보여 줍니다.

## 1. 템플릿 코드 만들기

```bash
npm run build:apps-script
```

`apps-script/Code.gs`(코드)와 `apps-script/appsscript.json`(매니페스트)이 만들어집니다. 조사 설정은 들어 있지 않은 공용 코드입니다.

## 2. 템플릿 시트 만들기

1. 제작팀 구글 계정으로 새 구글 시트를 만들고 이름을 붙입니다. (예: `[템플릿] 학생 기초조사 응답`)
2. **확장 프로그램 → Apps Script**를 열고, 편집기의 글을 모두 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
   - Apps Script 프로젝트 이름도 알아보기 쉽게 바꿉니다. (예: `학생 기초조사`) 선생님이 권한 허용 화면에서 이 이름을 보게 됩니다.
   - (선택) 왼쪽 **⚙ 프로젝트 설정 → ‘편집기에서 appsscript.json 매니페스트 파일 표시’**를 체크하고, `appsscript.json`을 열어 `apps-script/appsscript.json` 내용으로 바꿔 저장합니다. [새 배포] 창에서 ‘나 · 모든 사용자’가 미리 골라져 있게 하는 기본값만 들어 있고 권한 목록은 없습니다. 사본에 따라오는지는 확인되지 않았고, 따라오지 않아도 선생님이 두 항목을 고르면 되므로 건너뛰어도 됩니다.
3. 배포는 **하지 않습니다.** 사본을 만든 선생님이 각자 자기 계정으로 배포합니다.
4. 첫 번째 시트는 비워 둡니다. 시트를 열면 코드가 빈 `시트1`을 **`시작하기`** 시트로 바꾸고 할 일(설정 코드 복사 → 메뉴에 붙여넣기 → 배포)을 적어 둡니다. 원본 템플릿을 한 번 열어 안내가 적히는지 확인해 두세요. 선생님이 설정을 붙여넣어 조사가 준비되면 이 시트는 자동으로 지워지고 `제출현황` 시트가 맨 앞에 옵니다. 내용이 있는 `시트1`은 지우지 않습니다.

## 3. 공유 설정

**공유 → 일반 액세스: 링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
사본을 만들면 시트와 Apps Script 코드가 함께 복사되고, 사본의 주인은 선생님이 됩니다. 학생 응답은 선생님 사본에만 저장되고 제작팀 시트로는 오지 않습니다.

## 4. 프로그램에 주소 넣기

시트 주소(`https://docs.google.com/spreadsheets/d/…/edit`)를 `src/config.js`의 `SURVEY_TEMPLATE_COPY_URL`에 넣고 다시 빌드합니다.
주소 끝은 프로그램이 `/copy`로 바꿔서 씁니다.

```bash
npm run build
```

## 선생님이 밟는 단계

1. 프로그램의 [템플릿 사본 만들기]
2. 사본 시트 메뉴 **[📋 기초조사 → 설정 붙여넣기 / 바꾸기]**에 설정 코드 붙여넣기 → 저장. 같은 창에 배포 안내와 **[Apps Script 편집기 열기]** 버튼이 이어서 나오고, 편집기에서 [배포 → 새 배포 → 웹 앱 → 배포]
3. 웹 앱 URL을 프로그램의 5번 칸에 붙여넣기

배포 안내는 메뉴 **[배포(학생용 주소 만들기) 안내]**로 언제든 다시 볼 수 있습니다.

## 응답을 프로그램에서 바로 가져오기

프로그램의 6번 [구글 시트에서 지금 가져오기]는 5번 칸의 웹 앱 주소에 `?export=열쇠`를 붙여 응답을 받아옵니다. 열쇠는 프로그램이 조사마다 만들어 **설정 코드 안에 넣어 두므로** 선생님이 따로 할 일은 없습니다. 시트는 열쇠가 맞을 때만 `선택과목`·`제출기록`·`설정` 시트를 엑셀과 같은 행 모양으로 돌려주고, 학생 화면에는 열쇠를 보내지 않습니다.

이 기능은 웹 앱 코드(`doGet`)에 들어 있어서, **이 기능이 없는 코드로 이미 배포한 시트**는 새 `Code.gs`를 붙여넣은 뒤 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 한 번 해야 합니다. 새로 만드는 사본은 해당 없습니다. 시트를 엑셀로 내려받아 올리는 방법은 예비로 남아 있습니다.

## 자동 배포를 쓰지 않는 이유

시트 메뉴 버튼으로 배포하는 방법(Apps Script API)도 시험했지만 쓰지 않기로 했습니다.

- 사본을 만들면 사본마다 구글이 숨은 클라우드 프로젝트를 새로 붙이는데, 그 프로젝트에서 Apps Script API를 켜야 해서 선생님마다 클라우드 콘솔에 들어가야 합니다.
- 시험해 본 사본에서는 `appsscript.json`이 기본값으로 돌아가 있어서, 템플릿에 넣어 둔 웹 앱 설정과 권한 목록이 복사되지 않는 것으로 보였습니다.

그래서 선생님은 Apps Script 편집기에서 **[배포 → 새 배포 → 웹 앱]**으로 직접 배포하고, 프로그램이 이 창을 그림으로 안내합니다. (코드는 git 기록 `f595e02`~`038af56`에 남아 있습니다)

## 코드를 고친 뒤

`src/survey/appsScript.js`(학생 화면, 서버 코드, 설정 창)를 고쳤다면:

1. `npm run test:survey`로 확인합니다.
2. `npm run build:apps-script`로 `Code.gs`를 다시 만들어 템플릿 시트의 Apps Script에 붙여넣고 저장합니다.
3. 이미 사본을 만들어 쓰고 있는 선생님들의 시트는 자동으로 바뀌지 않습니다. 꼭 필요한 수정이면 새 설치 코드를 붙여넣고 **배포 관리 → 새 버전**으로 다시 배포하도록 안내해야 합니다.
