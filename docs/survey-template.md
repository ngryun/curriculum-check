# 학생 기초조사 템플릿 시트 만들기 (제작팀용)

선생님이 **[템플릿 사본 만들기]** 한 번으로 Apps Script 코드가 들어 있는 시트를 받게 하려면, 제작팀이 템플릿 시트를 한 번 만들어 공개해 두어야 합니다.
템플릿이 없으면(`src/config.js`의 `SURVEY_TEMPLATE_COPY_URL`이 비어 있으면) 프로그램은 ‘새 시트에 코드 붙여넣기’ 방법만 보여 줍니다.

## 1. 템플릿 코드 만들기

```bash
npm run build:apps-script
```

`apps-script/Code.gs`(코드)와 `apps-script/appsscript.json`(매니페스트)이 만들어집니다. 조사 설정은 들어 있지 않은 공용 코드입니다.

매니페스트에는 웹 앱 설정(실행: 나, 액세스: 모든 사용자)과 권한 목록이 들어 있습니다. 이게 있어야 선생님이 시트 메뉴의 **[학생용 주소 만들기]** 한 번으로 배포할 수 있습니다.

## 2. 템플릿 시트 만들기

1. 제작팀 구글 계정으로 새 구글 시트를 만들고 이름을 붙입니다. (예: `[템플릿] 학생 기초조사 응답`)
2. **확장 프로그램 → Apps Script**를 열고, 편집기의 글을 모두 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
   - Apps Script 프로젝트 이름도 알아보기 쉽게 바꿉니다. (예: `학생 기초조사`) 선생님이 권한 허용 화면에서 이 이름을 보게 됩니다.
   - 왼쪽 **⚙ 프로젝트 설정 → ‘편집기에서 appsscript.json 매니페스트 파일 표시’**를 체크합니다. 편집기 파일 목록에 생긴 `appsscript.json`을 열어 내용을 모두 지우고 `apps-script/appsscript.json` 내용을 붙여넣은 뒤 저장합니다.
3. 배포는 **하지 않습니다.** 사본을 만든 선생님이 각자 자기 계정으로 배포합니다.
4. 첫 번째 시트(`시트1`)에 안내 문구를 적어 두면 좋습니다. 예:
   > 위쪽 메뉴 [📋 기초조사 → 설정 붙여넣기]로 프로그램에서 복사한 설정 코드를 넣으세요. 메뉴가 안 보이면 새로고침하세요.

## 3. 공유 설정

**공유 → 일반 액세스: 링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
사본을 만들면 시트와 Apps Script 코드가 함께 복사되고, 사본의 주인은 선생님이 됩니다. 학생 응답은 선생님 사본에만 저장되고 제작팀 시트로는 오지 않습니다.

## 4. 프로그램에 주소 넣기

시트 주소(`https://docs.google.com/spreadsheets/d/…/edit`)를 `src/config.js`의 `SURVEY_TEMPLATE_COPY_URL`에 넣고 다시 빌드합니다.
주소 끝은 프로그램이 `/copy`로 바꿔서 씁니다.

```bash
npm run build
```

## 선생님 쪽에 필요한 것

[학생용 주소 만들기]는 Apps Script API로 배포합니다. 선생님 계정마다 처음 한 번 https://script.google.com/home/usersettings 에서 **Google Apps Script API**를 ‘사용’으로 바꿔야 합니다. 학교(교육청) 계정은 관리자가 막아 두었을 수 있어서, 프로그램에 ‘직접 배포하기’ 안내를 함께 남겨 두었습니다.

## 코드를 고친 뒤

`src/survey/appsScript.js`(학생 화면, 서버 코드, 설정 창)를 고쳤다면:

1. `npm run test:survey`로 확인합니다.
2. `npm run build:apps-script`로 `Code.gs`를 다시 만들어 템플릿 시트의 Apps Script에 붙여넣고 저장합니다.
3. 코드에서 새 구글 서비스(예: 드라이브, 메일)를 쓰게 되면 `src/survey/appsScript.js`의 `TEMPLATE_MANIFEST.oauthScopes`에도 권한을 더해야 합니다. 권한 목록을 직접 적었기 때문에 구글이 자동으로 찾아 주지 않습니다.
4. 이미 사본을 만들어 쓰고 있는 선생님들의 시트는 자동으로 바뀌지 않습니다. 꼭 필요한 수정이면 새 설치 코드를 붙여넣고 **배포 관리 → 새 버전**으로 다시 배포하도록 안내해야 합니다.
